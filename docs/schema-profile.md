# Pinned schema evaluation

The generator bundles the exact 14 OpenAPI documents of the public contract and locks every source SHA-256 together with the `contract_digest`. Runtime validation evaluates the assertion keywords present in that pinned set: local references and siblings, types (including type arrays and semantic integers), required/properties/additionalProperties, dependentRequired, enum/const with exact JSON numeric equality, allOf/anyOf/oneOf/not, if/then/else, string length/pattern/format, array items/length, object property counts, and numeric minima/maxima. The two x-sdk-numeric bound keywords also apply exact decimal comparisons to numeric strings. Other x-* fields preserve contract documentation and are not invented server-side conditional rules.

The format profile asserts UUID text syntax, Gregorian calendar dates, [RFC3986 generic ASCII URI syntax](https://www.rfc-editor.org/rfc/rfc3986), and [RFC5321 ASCII mailbox syntax](https://www.rfc-editor.org/rfc/rfc5321#section-4.1.2). URI validation is independent of the stricter HTTPS base URL/redirect dispatch policies. A report URL modeled as an ordinary string preserves Unicode text. Email validation includes quoted local-parts, single-label domains and IPv4/IPv6 address literals. International email/IRI formats are not asserted by these pinned schemas.

Projection first validates the full original schema, then selects a matching union branch and its applicable property schemas. Generated constructors, named accessors, exact JSON-name access and additional fields retain their original presence and numeric representation. The field inventory merges alternative names for discoverable accessors; it does not force an unrelated alternative's field type on accepted data.

JSON parsing/encoding, schema evaluation, projection, diagnostics, file inspection and helper loops each have finite budgets. Reaching a budget rejects the value or fails diagnostics closed; it is never treated as fiscal approval. Draft contract gaps and x-conditional notes remain contract/program gates.
